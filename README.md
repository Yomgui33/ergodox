# qmk_keymap
Current QMK keymap for my ergodox keyboard

**Base layer**
![Base layer](https://github.com/Yomgui33/ergodox/blob/main/images/00_base_layer.png)

---

## Référence des layers

### Légende

| Notation | Signification |
|---|---|
| `___` | Transparent (layer du dessous) |
| `[h]` | Appui long (tap-hold) |
| `TT(X)` | Double-tap pour verrouiller le layer X |
| `LT(X,k)` | Tap = `k`, Hold = layer X momentané |
| `OSL(X)` | One-shot layer X |
| `OSM(mod)` | One-shot modificateur |
